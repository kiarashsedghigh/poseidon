# General-width Poseidon profiles

The `poseidon-profiles` example supports the following x^5 configurations:

| Name | Width | Full rounds | Partial rounds |
|---|---:|---:|---:|
| poseidon-128-t3 | 3 | 8 | 57 |
| poseidon-128-t5 | 5 | 8 | 60 |
| poseidon-80-t3 | 3 | 8 | 33 |
| poseidon-80-t5 | 5 | 8 | 35 |
| poseidon-256-t6 | 6 | 8 | 120 |
| poseidon-256-t10 | 10 | 8 | 120 |
| poseidon-x | 9 | 8 | 57 |

These use the existing StarkWare field `p = 2^251 + 17*2^192 + 1`,
not BLS12-381. Names identify the paper's round profiles, not a security claim
for this field. In particular, x^5 is not invertible in the StarkWare field,
so these experimental constructions are not permutations. The additional
width-9 configuration has no claimed security level.

The base Cauchy matrix is `M[i][j] = (t+i+j)^-1 mod p`, matching the supplied
Python matrix construction. Round constants use the supplied self-shrinking
Grain algorithm with field size 252, 8 full rounds, and the profile's partial
round count. Thus these constants differ from both the legacy C constants and
the BLS12-381 values generated by `tools/poseidon_bls_parameters.py`.

`poseidon_profile_init` prepares the base or protected context. The protected
form uses supplied nonzero multipliers and rotates `[x0,...,x(t-1)]` right by
one when `SD_PERMUTE=1`. `SD_SCALE` and `SD_PERMUTE` use the same build options
as the width-3 code. Protected outputs retain their transformation. The full
and partial matrices follow `D M D^-5` and
`D M diag(a0^-5,a1^-1,...,a(t-1)^-1)`, with row/column rotation when enabled.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DSD_PERMUTE=ON -DSD_SCALE=ON
cmake --build build --target poseidon-profiles
./build/poseidon-profiles poseidon-x
./build/poseidon-profiles poseidon-128-t3
```

The example uses state `[1,...,t]` and multipliers `[1,2,3,1,...]`. This is a
separate path; existing width-3 examples and the `perf` benchmark retain their
original constants and parameters. To exercise this path without CMake:

```sh
cc -O3 -fPIC -shared -Isources sources/poseidon_profiles.c sources/f251.c sources/f251_int128.c -o /tmp/poseidon_profiles.so
python3 tests/test_poseidon_profiles.py
```
